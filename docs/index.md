# FlashKeras

Welcome to the official documentation for **FlashKeras**.

FlashKeras is a Python library designed to simplify the development, training, evaluation, and analysis of machine learning models.

## Modules

The library is organized into the following modules:

- **Analysing** — tools for analyzing models and their results.
- **Data Collecting** — utilities for collecting and handling data.
- **Evaluation** — functions and tools for evaluating model performance.
- **Models** — classes and components for creating and training models.
- **Preprocessing** — utilities for preparing and transforming data.
- **Utils** — general-purpose utility functions used throughout the library.
